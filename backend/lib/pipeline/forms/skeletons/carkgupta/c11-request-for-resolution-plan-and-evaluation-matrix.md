# C11: Request for Resolution Plan and Evaluation Matrix
**Statutory Authority:** `Regulations 36A, 36B | Regulation 2(1)(ha)`

C11   Request for Resolution Plan and Evaluation Matrix

Regulations 36A, 36B | Regulation 2(1)(ha)

WHAT THE CODE PRESCRIBES

Form G for the invitation of expressions of interest.

WHAT IT DOES NOT PRESCRIBE

No format for the request for resolution plan itself, nor for the evaluation matrix that must accompany it.



WHY IT MATTERS

The matrix must be quantifiable and must be issued before the plans are received. Matrices altered after receipt of plans are the most reliably successful ground of challenge.

PROMPT

Act as counsel to a resolution professional. Draft the skeleton of a request for resolution plan under Regulation 36B, and a quantifiable evaluation matrix with parameters, weights and the scoring method. Every parameter must be capable of objective scoring from the face of a plan. Flag any parameter that requires a subjective judgement and suggest how to make it measurable.

Attach the bare provision to the project before running this. Verify every citation before use.
