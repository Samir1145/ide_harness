# G12: Discharge Application Record
**Statutory Authority:** `Sections 119, 120`

G12   Discharge Application Record

Sections 119, 120

WHAT THE CODE PRESCRIBES

That a discharge order may be applied for on completion of the plan, and the effect of discharge.

WHAT IT DOES NOT PRESCRIBE

No format for the application record, nor for the schedule of debts which are and are not discharged.



WHY IT MATTERS

Discharge does not extinguish every debt. Where the schedule is not drawn at the time, the debtor discovers the exclusions years later, and so does the professional.

PROMPT

Act as counsel to a resolution professional under Section 119. Draft a discharge application record with a schedule distinguishing the debts discharged by the order from those which are not, with the provision relied on for each exclusion. Attach the completion certificate and the payment reconciliation, and identify the persons on whom the application must be served.

Attach the bare provision to the project before running this. Verify every citation before use.



DRAFT TEMPLATE — HEADS TO CARRY

Reference to the approved plan and the completion certificate

Payment reconciliation, creditor-wise

Schedule A — debts discharged by the order

Schedule B — debts not discharged, with the provision

Excluded debts and the reason for exclusion

Position of co-obligors and sureties

Persons on whom the application is to be served

Relief sought in the application

Effect of the discharge, stated plainly for the debtor
