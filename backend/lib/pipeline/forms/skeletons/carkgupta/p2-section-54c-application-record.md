# P2: Section 54C Application Record
**Statutory Authority:** `Section 54C`

P2   Section 54C Application Record

Section 54C

WHAT THE CODE PRESCRIBES

The form and manner of the application, and the documents to accompany it.

WHAT IT DOES NOT PRESCRIBE

No format for the composite index correlating every document required by Section 54C to the annexure that carries it.



WHY IT MATTERS

A pre-packaged application is refused at the threshold more often for an incomplete annexure set than for any substantive reason.

PROMPT

Act as counsel to a corporate debtor filing under Section 54C. Draft an application record indexing every document the section requires against the annexure that carries it, with the date of each document and a confirmation that it remains current on the date of filing. Flag any document that is stale or missing.

Attach the bare provision to the project before running this. Verify every citation before use.
