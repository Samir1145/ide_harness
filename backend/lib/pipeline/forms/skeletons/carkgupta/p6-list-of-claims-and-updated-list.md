# P6: List of Claims and Updated List
**Statutory Authority:** `Section 54F | PPIRP Regulations`

P6   List of Claims and Updated List

Section 54F | PPIRP Regulations

WHAT THE CODE PRESCRIBES

The forms for the submission of claims and the obligation to prepare and update the list.

WHAT IT DOES NOT PRESCRIBE

No format for the list itself, nor for the record of each update and what caused it.



WHY IT MATTERS

In a compressed process the list changes several times. Without a record of what changed and when, the committee cannot know which version it voted on.

PROMPT

Act as counsel to a resolution professional in a pre-packaged process. Draft a list of claims and an update register. The register must record, for each version, the date, what changed, the claim affected, the reason and the effect on voting shares. Cross-reference each version to the meeting at which it was placed.

Attach the bare provision to the project before running this. Verify every citation before use.
