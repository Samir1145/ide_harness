# P9: Challenge Process Document
**Statutory Authority:** `Section 54K(4) to (12)`

P9   Challenge Process Document

Section 54K(4) to (12)

WHAT THE CODE PRESCRIBES

The statutory scheme of the challenge process and the improvement thresholds.

WHAT IT DOES NOT PRESCRIBE

No format for the process document setting out the rounds, the timings, the improvement increments and the tie-break rule.



WHY IT MATTERS

The challenge process runs live, in rounds, under time pressure. Anything not written down before it starts cannot be settled while it is running.

PROMPT

Act as counsel to a resolution professional in a pre-packaged process. Draft a challenge process document under Section 54K, setting out eligibility to participate, the rounds and their duration, the minimum improvement in each round, the evaluation basis, the tie-break rule, the platform and the record to be maintained. Every rule must be capable of being applied without further judgement while the process is running.

Attach the bare provision to the project before running this. Verify every citation before use.



DRAFT TEMPLATE — HEADS TO CARRY

Eligibility to participate and the plans admitted

Number of rounds and the duration of each

Minimum improvement required in each round

Evaluation basis and how scores are computed

Tie-break rule

Platform, connectivity failure and extension rules

Conduct rules and grounds for disqualification

Record of each round to be maintained

Declaration of the result and its finality
