# C12: Avoidance Transaction Determination
**Statutory Authority:** `Sections 43, 45, 49, 50, 66 | Regulation 35A`

C12   Avoidance Transaction Determination

Sections 43, 45, 49, 50, 66 | Regulation 35A

WHAT THE CODE PRESCRIBES

The timeline — opinion, determination and application, by the stipulated days from commencement.

WHAT IT DOES NOT PRESCRIBE

No format for the opinion, for the determination, or for the application to the Adjudicating Authority.



WHY IT MATTERS

The statute contemplates three distinct stages of reasoning. Where they collapse into one document, the application is vulnerable at the threshold.

PROMPT

Act as counsel to a resolution professional. Draft the three-stage record under Regulation 35A: first the opinion that the corporate debtor has been subjected to a transaction of a kind covered by Sections 43, 45, 50 or 66; then the determination with the specific transactions identified; then the skeleton of the application. Keep the three stages separate and date each. Cite the look-back period applicable to each Section.

Attach the bare provision to the project before running this. Verify every citation before use.



DRAFT TEMPLATE — HEADS TO CARRY

Stage 1 — opinion, with the material that founded it

Look-back period applicable to each Section

Related party status and its effect on the look-back

Stage 2 — determination, transaction by transaction

Classification: preferential | undervalued | extortionate | fraudulent

Transaction audit report relied on, if any

Stage 3 — application skeleton and relief sought

Persons to be arrayed as respondents

Dates recorded against the Regulation 35A timeline
