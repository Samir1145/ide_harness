# P10: Approval and Implementation Record
**Statutory Authority:** `Sections 54K, 54L`

P10   Approval and Implementation Record

Sections 54K, 54L

WHAT THE CODE PRESCRIBES

The approval of the plan by the committee and by the Adjudicating Authority, and the effect of approval.

WHAT IT DOES NOT PRESCRIBE

No format for the record tracking implementation of the approved plan against its own milestones.



WHY IT MATTERS

A pre-packaged plan is approved quickly and implemented over years. The implementation record is what a monitoring committee will ask for, and it is usually created only when it is demanded.

PROMPT

Act as counsel to a resolution professional in a pre-packaged process. Draft an implementation tracking record for an approved plan, listing each milestone with its due date, the actual date, the evidence of performance, and the consequence provided in the plan for a default. Add a section on reliefs granted and the authority before whom each is to be pursued.

Attach the bare provision to the project before running this. Verify every citation before use.



DRAFT TEMPLATE — HEADS TO CARRY

Approval order, date and its effective date

Milestone-wise: due date, actual date, evidence

Payments to each class against the plan schedule

Performance security and its status

Monitoring committee, if any, and its meetings

Reliefs granted and the authority for each

Defaults, and the consequence provided in the plan

Deviation from the plan and its approval
