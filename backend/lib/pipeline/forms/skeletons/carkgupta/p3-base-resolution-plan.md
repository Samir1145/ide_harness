# P3: Base Resolution Plan
**Statutory Authority:** `Sections 54A, 54K | PPIRP Regulations`

P3   Base Resolution Plan

Sections 54A, 54K | PPIRP Regulations

WHAT THE CODE PRESCRIBES

That a base resolution plan shall be submitted by the corporate debtor along with the application.

WHAT IT DOES NOT PRESCRIBE

No format for the base resolution plan.



WHY IT MATTERS

The base plan sets the floor for the entire process. It is prepared before the process even begins, and there is no prescribed structure for it.
