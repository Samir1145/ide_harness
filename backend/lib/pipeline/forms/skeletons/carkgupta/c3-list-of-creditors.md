# C3: List of Creditors
**Statutory Authority:** `Regulation 13(2)(c) and 13(2)(ca)`

C3   List of Creditors

Regulation 13(2)(c) and 13(2)(ca)

WHAT THE CODE PRESCRIBES

The obligation to file the list with the Adjudicating Authority, host it on the website and file it with the Board.

WHAT IT DOES NOT PRESCRIBE

No format for the list itself, although it is a public document and must reconcile exactly with the voting share table.



WHY IT MATTERS

The list is read by every prospective resolution applicant and by every dissatisfied creditor. A list that does not tie to the CoC voting shares invites a challenge to the constitution of the committee.

PROMPT

Act as counsel to a resolution professional. Draft the format of a list of creditors under Regulation 13(2)(c), separately for financial creditors, financial creditors in a class, operational creditors, workmen and employees, and other stakeholders. Show amount claimed, amount admitted, security interest and voting share. Add a reconciliation line tying admitted financial debt to total voting share.

Attach the bare provision to the project before running this. Verify every citation before use.
