# P1: Pre-Commencement Declarations Record
**Statutory Authority:** `Section 54A(2) and (3)`

P1   Pre-Commencement Declarations Record

Section 54A(2) and (3)

WHAT THE CODE PRESCRIBES

The declarations, the special resolution and the financial creditor approval required before an application is filed.

WHAT IT DOES NOT PRESCRIBE

No format for the composite record showing that every pre-condition was satisfied, and in the correct sequence.



WHY IT MATTERS

Section 54A is a sequence, not a list. An application filed with the steps out of order is defective on its face.

PROMPT

Act as counsel to a corporate debtor proposing a pre-packaged process. Draft a pre-commencement compliance record under Section 54A, listing every pre-condition with the date on which it was satisfied and the document evidencing it, arranged in the statutory sequence. Flag any step taken out of sequence.

Attach the bare provision to the project before running this. Verify every citation before use.
