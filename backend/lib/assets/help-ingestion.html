Ingestion Management System (IMS)

Document Ingestion & 3-Dot Status Pipeline

Complete practitioner guide to local document processing, OCR, companion Markdown, and knowledge graphs.

100% Air-Gapped Local-First Enclave

All document parsing, optical text recognition, lexical indexing (FTS5), and vector generation (InLegal-SBERT ONNX) execute entirely inside your local machine. Zero bytes of client data or case dossiers ever leave your hardware.

Understanding the 3 Green Status Dots

Every legal document (PDF, Word, Excel, Markdown) displays 3 status dots in the Explorer tree indicating where it stands in the sovereign AI processing pipeline:

1

Dot 1: Companion Markdown Conversion & Live Authoring

When a binary document (e.g. PDF or DOCX) is added to a case folder, Hayagriva immediately extracts its text and tables into a clean, editable companion Markdown file (.md).

Right-Click ➔ 🟢 1. Review Companion (Edit & Live Preview)

Selecting this closes the heavy PDF viewer and docks the Monaco Editor on the left and the Live HTML Preview on the right. Any edits you make sync live on Cmd+S.

2

Dot 2: Lexical FTS5 Indexing & Dual-Vector Embedding

The companion Markdown is sliced into structural sections and semantic chunks. Chunks are simultaneously registered in the SQLite FTS5 search index and embedded via local ONNX neural models:

  • Legal Text & Orders: Embedded using InLegal-SBERT (768d vector space).
  • Financial Sheets & Ledgers: Embedded using Finance-Embeddings for tabular arithmetic.
Right-Click ➔ 🟢 2. Re-Index into AI Memory (Vector & FTS5)
3

Dot 3: Case Fact & Variable Extraction (K-V)

The background worker identifies and extracts essential statutory variables into case_kv_dictionary.json: Corporate Debtor names, admission order dates, debt quantum, admitted financial claims, and IRP details.

Right-Click ➔ 🟢 3. Extract Case Facts & Claims (K-V)

Extracted facts auto-populate into court skeletons when drafting via @Document or /template.

Safe 7-Day Trash Deletion

Legal dossiers are high-stakes. Hayagriva replaces accidental destructive file deletes with a safe 7-day retention vault:

Soft-Delete to .trash/

Selecting 🗑 Delete File (move to trash) safely moves the document, companion files, and vector indices into .trash/ for 7 days before permanent removal.

You can restore any trashed file within 7 days directly from the 🔒 Vault & Archival top menu.
