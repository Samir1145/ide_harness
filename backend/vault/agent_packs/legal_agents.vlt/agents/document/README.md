# Document Agent

Legal reports, minutes, resolutions drafting compiler.

## Folder Layout
* `agent.js` — Core execution file. Coordinates draft compilations and critique loops.
* `agent.md` — System instructions for legal formatting.
* `README.md` — This file.

## Execution
Selects target templates, compiles draft files by replacing placeholder variables, runs automated critique audits via the Forms Agent, and saves draft versions.
