# @plan-evaluator Subagent

The `@plan-evaluator` agent audits Resolution Plans against mandatory Section 30(2) requirements and Section 29A disqualification criteria under the Insolvency and Bankruptcy Code (IBC), 2016. It also compiles the official Regulation 39(4) Form H Compliance Certificate.

## Triggers
`@evaluator`, `@plan-audit`, `@form-h`

## Key Capabilities
- **Section 30(2) Compliance Matrix**: Audits CIRP cost priority, Operational Creditor minimum payouts, and management control plans.
- **Section 29A Ineligibility Check**: Verifies connected persons, NPA history (>1 year), and MCA-21 director disqualification records.
- **Form H Compiler**: Auto-populates all 16 tables of Form H for submission to NCLT.
