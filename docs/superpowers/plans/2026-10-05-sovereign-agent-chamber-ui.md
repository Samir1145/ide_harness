# Sovereign Legal Coworker Chamber UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-architect the Hayagriva IDE UI from a generic software developer layout into a Sovereign Legal Coworker Chamber featuring the Flowing Stallion emblem, top `Agents` menu & cockpit switchboard, dynamic Coworker Agent activity bar with pinned `@Registry`, stuck `⚡ LightRAG` precedent drawer, and 3-tier workstation accordions (`📁 Case Documents`, `💬 Instructions`, `🕸️ Relationship Chart`).

**Architecture:** 
Deconstruct the monolithic IDE sidebar into a dynamic coworker desk driven by matter manifest state (`active_coworkers`). Replace top window branding with a vector-masked amber Flowing Stallion that opens the Chamber Cockpit, register a 1st-class top menubar `Agents` category for catalog activation and task auditing, relocate notifications to the top header right and billing to the cockpit, dock `⚡ LightRAG` permanently above `👤 Profile` to drive slide-over precedent inquests while retiring the floating orb, and equip each coworker with a 3-tier collapsible accordion workstation defaulting legal drafts to formatted Milkdown Word View.

**Tech Stack:** 
Eclipse Theia 1.75.0 (TypeScript, Phosphor/Lumino widgets, InversifyJS DI, MenuModelRegistry, CommandRegistry), Milkdown WYSIWYG Legal Word View, Monaco Editor, D3.js forensic graph topology, Node.js backend daemon (port 3210).

## Global Constraints

- **No Open Editors:** `#theia-open-editors-widget` must NEVER be displayed in the left navigator (suppressed via CSS and `explorer.openEditors.visible: 0`).
- **Terminology Enforcement (Option 2):** Agent accordion titles must strictly be `📁 Case Documents`, `💬 Instructions`, and `🕸️ Relationship Chart` — avoid technical jargon like `Dossier`, `Talk`, or `Topology`.
- **Zero Floating Overlay:** The floating AskHaya Fluid Glass Orb (`#hayagriva-askhaya-orb-root`) is completely retired from floating on the canvas; precedent and ambient voice counsel are delivered via the docked `⚡ LightRAG` slide-over drawer.
- **Sovereign Air-Gap Floor:** No external LLM, cloud API, or decrypted bare act vault is required for basic UI rendering, manifest parsing, or local Lite Mode operation.
- **Draft Delivery Standard:** Legal drafts generated by any coworker must automatically open in formatted Milkdown Legal Word View with a 1-click toggle to raw Monaco markdown.

---

## Review Focus

1. **Top Flowing Stallion Vector Mask:** The top-left emblem must render a crisp flowing stallion silhouette without clipping, pixelation, or reverting to the deity mask.
2. **Dynamic Coworker Bar Updates:** Toggling an agent in `Agents -> Manage Agents` must immediately update the left activity bar roster without requiring a full workbench reload.
3. **Non-Disruptive LightRAG Drawer:** Clicking `⚡ LightRAG` above `👤 Profile` must slide over the precedent drawer without unmounting or resetting the active agent's conversational state.
4. **Accordion State Integrity:** Collapsing or expanding sections in the 3-tier workstation (`📁 Case Documents`, `💬 Instructions`, `🕸️ Relationship Chart`) must preserve scroll position and input values.
5. **Zero Collateral Build Breakage:** All TypeScript code across `frontend/theia-extensions/hayagriva` and `frontend/applications/browser` must compile cleanly with zero diagnostic errors.
